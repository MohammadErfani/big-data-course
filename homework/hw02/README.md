# Query Counter

## تمرین

1. برنامه ای بنویسید که به صورت تصادفی کوری بسازد. تعداد کلمات هر کوری حداکثر دو کلمه ی انگلیسی می باشد. تعداد حروف هر کلمه نیز حداکثر 3 حرف می باشد. توجه داشته باشید که در دو کوری یکسان ممکن است جای کلمات جابجا باشد.

2. برنامه ای با structured spark streaming بنویسید، که تعداد تکرار کوریها در 24 ساعت گذشته را محاسبه کرده و با تاخیر حداکثر 5 دقیقه ای در خروجی نمایش دهد.

## برنامه ساخت کوئری تصادفی

داخل فایل generator.py کد مربوطه قرار دارد. اگر برنامه کوئری‌های کاملا تصادفی تولید کند، احتمال وجود دو کوئری یکسان پایین می‌آید که امکان فهمیدن درست کار کردن برنامه را دشوار می‌کند. برای این منظور داده‌ها کاملا تصادفی نخواهند بود. همچنین داده‌های تصادفی تولید شده به صورت فایل با فرمت JSON در پوشه input قرار می‌گیرند.
